# Sprint 6: Автотесты для сервиса Яндекс.Самокат

Проект автоматизированного тестирования пользовательского интерфейса учебного сервиса «Яндекс.Самокат». Реализован с использованием паттерна Page Object Model и фреймворка Allure для генерации отчетов.

## Функциональность

Проект покрывает автотестами следующие функциональные блоки:

### Раздел "Вопросы о важном" (аккордеон)
- Проверка корректности открытия/закрытия ответов
- 8 параметризованных тестов для каждого вопроса
- Валидация текстового содержания ответов

### Процесс заказа самоката
- Тестирование через две точки входа (верхняя и нижняя кнопки "Заказать")
- Два набора тестовых данных с различными пользовательскими данными
- Полный цикл позитивного сценария: заполнение форм → подтверждение → проверка результата

### Навигация по сайту
- Проверка перехода на главную страницу по логотипу Самоката
- Проверка открытия Дзена в новом окне по логотипу Яндекса

## Технологии

- **Язык программирования:** Python 3.13.5
- **Фреймворк автоматизации:** Selenium WebDriver 4.15.0
- **Браузер для тестирования:** Mozilla Firefox
- **Фреймворк тестирования:** Pytest 7.4.0
- **Система отчетности:** Allure Framework 2.13.2
- **Архитектура:** Page Object Model

## Установка и запуск

### Предварительные требования
- Установленный Python 3.13+
- Установленный Mozilla Firefox
- Установленный Allure Commandline

### Установка зависимостей

pip install -r requirements.txt
Запуск тестов
bash
# Полный набор тестов с генерацией отчета
python -m pytest tests/ --alluredir=allure-results -v

# Запуск отдельных тестовых групп
python -m pytest tests/test_accordion.py -v
python -m pytest tests/test_order.py -v
python -m pytest tests/test_navigation.py -v
Генерация отчетов
bash
# Интерактивный отчет
allure serve allure-results

# Статический отчет
allure generate allure-results -o allure-report --clean
